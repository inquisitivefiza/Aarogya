# 🧘‍♀️ Aarogya — AI-Powered Fitness Coach

> **Train smarter. Move better. Stay consistent.**

Aarogya is an AI-powered Android fitness companion designed to provide **real-time workout guidance, personalized fitness recommendations, nutrition insights, and wearable-based activity tracking** in one platform.

### ✨ Features

* 🤖 **Real-Time Pose Correction** — Uses **MoveNet, TensorFlow Lite, MediaPipe, and OpenCV** to analyze body movements and provide workout form feedback.
* 💪 **Personalized Workouts** — Generates recommendations based on fitness goals, activity, and progress.
* 🥗 **Nutrition Insights** — Provides meal analysis and personalized macronutrient recommendations.
* 🔥 **Challenges & Leaderboards** — Uses gamification to encourage consistency and engagement.
* ⌚ **Wearable Integration** — Supports Fitbit, Wear OS, and Bluetooth fitness trackers for activity data.
* 💾 **Offline Data** — Uses Room Database for local fitness and progress storage.

### 🛠️ Tech Stack

**Kotlin · Jetpack Compose · TensorFlow Lite · MoveNet · MediaPipe · OpenCV · FastAPI · Firebase · Room · Fitbit · Wear OS**

### 🌍 Value

Aarogya brings **AI-assisted coaching, fitness tracking, nutrition guidance, and motivation** into a single mobile experience, reducing dependence on separate tools while making personalized fitness guidance more accessible.
